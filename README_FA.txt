Toobit Auto Paper Trader V11 — راهنمای نصب روی Render
====================================================

این نسخه بر پایه اسکنر V10 کاربر ساخته شده است. موتور کشف Pump/Dump و امتیاز مستقل Entry حفظ شده و موتور Paper Trading به آن اضافه شده است.

مهم: این برنامه فقط معاملات مجازی انجام می‌دهد و هیچ سفارش واقعی به Toobit ارسال نمی‌کند. برای تست و ارزیابی است، نه توصیه سرمایه‌گذاری.

فایل‌ها
-------
app.py              برنامه FastAPI، داشبورد موبایل و موتور معاملات آزمایشی
requirements.txt    وابستگی‌های پایتون
render.yaml         تنظیمات سرویس Render

استقرار
-------
1) یک Repository جدید در GitHub بساز تا نسخه قبلی V10 دست‌نخورده بماند.
2) محتوای این پوشه را در ریشه Repository بارگذاری کن.
3) در Render گزینه New + > Web Service را بزن و Repository جدید را متصل کن.
4) Build Command:
   pip install -r requirements.txt
5) Start Command:
   uvicorn app:app --host 0.0.0.0 --port $PORT
6) Health Check Path:
   /api/health
7) Deploy را اجرا کن و پس از بالا آمدن، آدرس سرویس را باز کن.

تنظیمات پیش‌فرض معاملات آزمایشی
------------------------------
سرمایه مجازی: 1000 USDT
چرخه اسکن موتور معاملات: هر 300 ثانیه (5 دقیقه)
حداکثر معاملات باز: 5
حداکثر ارزش اسمی هر معامله: 5 درصد Equity
بودجه ریسک هر معامله تا SL: 0.5 درصد Equity
حداقل امتیاز Entry: 65
حداقل امتیاز کل Long/Short: 65
کارمزد فرضی هر سمت: 0.06 درصد
لغزش فرضی هر سمت: 0.05 درصد
خروج مرحله‌ای: چهار هدف، هرکدام حداکثر 25 درصد حجم اولیه
پس از TP1: انتقال SL به قیمت ورود

نکات مهم Render رایگان
---------------------
- سرویس رایگان Render ممکن است پس از حدود 15 دقیقه بدون درخواست ورودی به خواب برود. در مدت خواب، Thread معاملات پس‌زمینه هم اجرا نمی‌شود.
- فایل SQLite روی دیسک موقت سرویس قرار می‌گیرد و با Restart یا Deploy ممکن است پاک شود. این نسخه برای تست اولیه است؛ برای نگهداری قابل اتکای تاریخچه و اجرای دائمی باید بعداً از دیسک/پایگاه‌داده پایدار و Worker دائمی استفاده شود.
- داشبورد هر 15 ثانیه وضعیت را تازه می‌کند؛ این فقط وقتی صفحه باز است درخواست ورودی ایجاد می‌کند و تضمین اجرای 24/7 نیست.
- موتور خودکار با شروع برنامه فعال است. از دکمه داشبورد می‌توان آن را متوقف یا دوباره فعال کرد.
- برای شروع، هیچ API Key صرافی لازم نیست و نباید کلید خصوصی در کد قرار داده شود.

APIهای کمکی
------------
GET  /api/health
GET  /api/paper/status
GET  /api/paper/trades
GET  /api/paper/events
POST /api/paper/control   بدنه نمونه: {"enabled": false}

توجه: اگر API عمومی Toobit در دسترس نباشد، در داشبورد خطا ثبت می‌شود و چرخه بعدی دوباره تلاش می‌کند.
